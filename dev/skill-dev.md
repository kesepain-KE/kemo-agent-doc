# 技能开发

技能是注入 system prompt 的 Markdown 指令，不注册 Provider 可执行函数。它适合承载工作方法、领域规范和可重复流程。

## 作用域

| 作用域 | 路径 | 可用范围 |
|---|---|---|
| 共享 | `shared_skills/<name>/` | 被主配置允许的所有用户 |
| 用户 | `users/<user>/user_skills/` | 当前用户 |

一个技能唯一必需文件是 `SKILL.md`，可附带 `references/`、`scripts/` 和 `assets/`。

## 基本写法

```markdown
# code-review

审查代码正确性和可维护性的工作流程。

## 使用原则

- 先读取目标和相邻代码。
- 优先报告可复现问题。

## 操作流程

1. 确认修改范围。
2. 检查行为、错误处理和测试。
3. 按严重程度输出结论。
```

技能可以带 `## Tool` JSON 作为参数文档，但这只影响提示词，不会产生可执行工具。真正需要 function call 时应开发插件。

## 选择标准

- 只需要告诉模型“怎样做”：技能。
- 需要运行 Python、访问文件或外部服务：插件。
- 需要独立模型调用和隔离授权：子代理。

主智能体通过 `skills.shared_whitelist` 过滤共享技能；用户技能按当前用户目录发现。
