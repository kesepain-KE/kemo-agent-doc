# kemo-agent-app 1.1.2 — 账号加密导入导出

1.1.1 让账号管理更顺手；1.1.2 解决的是"换机时账号怎么安全搬走"的问题——账号现在可以导出为密码加密的 `.kemoaccount` 文件，在另一台设备上导入即恢复，凭据全程不落明文。

## 本次更新

| 领域 | 变更 |
|------|------|
| 账号导出 | 账号操作弹窗新增「导出账号」：设置文件加密密码（至少 8 位）后经系统文件选择器选择保存位置 |
| 账号导入 | 「添加账号」下方新增「导入账号」：选择 `.kemoaccount` 文件并输入导出密码，凭据重新经 Android Keystore 加密保存 |
| 文件格式 | `KEMOACC1` 格式头 + 随机盐 + 随机 IV + AES-256-GCM 认证密文；密钥由 PBKDF2-HMAC-SHA256（210,000 次迭代）派生；单文件上限 1 MiB |
| 安全边界 | 导出文件不含本机 App 解锁密码；未保存在本机的用户密码无法导出；文件只在本机解密、不上传服务器；错误密码、文件篡改、非法头均被 GCM 认证或显式校验拒绝 |
| 细节 | 导入不切换当前账号；导入当前账号时自动重连 WebSocket；密码与派生密钥用完即清零 |
| 版本 | 构建配置、README 徽章、中英文版本资源、CI 与发布合同统一 1.1.2（versionCode 4） |
