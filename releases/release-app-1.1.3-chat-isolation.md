# kemo-agent-app 增量 — 账号级聊天会话隔离

1.1.3 优化了更新链路；这次增量解决的是多账号共存的体验——每个账号的聊天历史与会话独立保存、独立恢复，切换账号不再互相干扰。

## 核心变更

| 层面 | 变更 |
|------|------|
| 本地存储 | 新增 `AccountChatState` 按账号存储聊天历史与会话 ID；旧版单份聊天字段带归属迁移，删除账号同步清理其聊天状态 |
| 会话恢复 | 启动/切换账号时优先查询桥接活跃会话（`/v1/conversations/active`），无活跃会话回退最近未关闭会话，都没有则新建 `app-` 会话 |
| 切换保护 | 账号切换按 epoch 隔离异步结果，旧账号响应不会污染新账号界面；忙碌（对话中/上传中/引导提交）时拒绝切换并提示 |
| 界面重组 | 聊天页按当前账号 `key` 重组，避免 Compose 状态残留 |
| 测试 | 新增 `AccountChatStateTest`：账号状态隔离、遗留状态只归属记录账号 |
