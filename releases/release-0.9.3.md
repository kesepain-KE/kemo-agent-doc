# v0.9.3 更新说明

`v0.9.3` 是一次上下文安全与记忆单向性修复。它防止超大工具返回一次性撑满模型上下文，并切断“临时重要热画像反向加权临时三层”的自我强化回路。此次更新不改变用户配置、历史存储或记忆文件 schema。

## 工具结果上下文保护

- 主对话、子代理和任务计划统一限制单次工具内联 JSON 结果最多 20,000 字符。
- 超限时完整正文被丢弃，只返回 `ToolResultTooLargeError`、原始字符数和缩小读取范围的提示。
- 超大正文不进入 Provider 输入、运行事件、`tool.json` 或 `items.json`，最近工具轮次的上下文重建也有二次限制。
- 这类受控拒绝不计入连续工具失败；读取大文件时应先用 `file.stat`，再用 `file.read_range` 按行或尾部分段读取。

## 临时记忆单向边界

- 记忆数据流固定为“用户对话原文 → 临时三层 → 临时重要热画像”。
- 后台 `context_compression` 和 `memory_promotion` 模式无法搜索 `important`，临时重要记忆不再能反向参与临时三层的整理或晋升。
- 后台提取只向 `self_improve` 传入用户消息；助手回复、reasoning/think 和工具结果被移除。
- 每个候选的 `evidence` 必须能在本批用户原文中精确找到，否则运行时拒绝落盘。
- Prompt 注入、用户查看和工具搜索都是只读行为，不改变临时记忆权重。用户主动的 `manual_review` 仍可只读访问临时重要记忆。

## 版本与验证

根版本和 core 为 `0.9.3`；agents 升级为 `0.8.1`，plugins 升级为 `0.8.2`，web 保持 `0.9.0`。后端全量测试结果为 `666 passed, 2 skipped, 49 subtests passed`，前端生产构建通过。

## 升级步骤

```bash
python update.py --module all
```

更新完成后完整重启 kemo-agent，使新的工具结果限制和记忆提取边界生效。
