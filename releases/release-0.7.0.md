# v0.7.0 更新说明

`v0.7.0` 统一收录 2026 年 7 月 28 日已经推送和尚未推送的全部改动。当天较早发布的 `v0.6.0` 是 Kemo 网关接入的中间版本点；模型目录、网关状态拓展和协议加固也一并纳入本次正式更新口径。升级前建议备份 `.env`、`users/`、外部消息模块和自建拓展。

## Web 后端领域分层

- `web/app.py` 收敛为 FastAPI 应用装配、共享运行时初始化和路由注册入口。
- 新增 `web/routes/`，按身份、会话、文件、模块、设置和任务等功能域声明 HTTP 路由。
- 新增 `web/services/`，承载文件、知识、记忆、技能、用户、运行状态等领域逻辑。
- `web/service.py` 保留兼容门面与聊天核心，既有 API 路径和测试入口不因拆分而改变。
- 公共请求模型、异常和容量限制分别进入 `web/schemas.py`、`web/errors.py` 和 `web/constants.py`。
- 更新器的 web 板块会递归同步这些新目录和合同文件，部署机无需手动创建目录。

## 文件空间媒体预览

- 文件空间中的图片、音频和视频可以在卡片中直接预览或播放，并可在独立标签页打开。
- 音频和视频保留浏览器原生进度条、播放、音量等控制。
- 图片、音频和视频的预览上限分别为 10 MB、100 MB 和 300 MB；超过上限时仍可管理文件，但不加载预览。
- 预览 API 同时校验用户范围、目录边界、普通文件身份、扩展名和 MIME 类型，不放宽原有文件安全边界。

## 用户技能 ZIP 安装

- 技能页新增“上传用户技能”，只接受 ZIP，并且只写入当前用户的 `user_skills/user_create/`。
- 服务递归、大小写不敏感地发现 `SKILL.md`，保留技能目录中的完整项目结构；一个压缩包可以安装一个或多个技能。
- 安装采用 staging 和整包事务提交，任意技能校验失败都会回滚，不留下半安装目录，也不会覆盖现有同名技能。
- 路径穿越、符号链接、加密或损坏归档、大小写冲突、异常压缩比以及超过大小、文件数、技能数限制的归档都会被拒绝。

## 记忆与知识浏览

- `memory_manage` 升级到 `v1.5.0`，`search_by_title`、`search_by_content` 和 `search_many` 支持 `tier: "all"`，一次搜索七天、一个月、半年和永久四层记忆碎片。
- 跨层结果携带真实层级和 `memory_ref`，便于继续精确读取；列出、获取和增删改仍必须指定具体层级。
- 知识页四个范围概览卡片可以直接点击切换，知识文件改为统一卡片风格并固定每页 10 个。
- 记忆筛选和选中态降低色调，搜索输入与页面主题保持一致。

## Web 界面与对话体验

- 长对话右侧导航改为更稳定的圆弧卡片滚轮，悬停刻度时按位置展示相邻用户消息，点击卡片会跳转到对应轮次。
- 去除多余的半圆轨道、圆点和尖角装饰，减少鼠标移位和视觉干扰。
- 文件空间的顶部信息与列表容器合并为统一卡片；知识、记忆、技能、Provider 设置等页面统一间距、渐变、选中态和输入框样式。
- API 失败后的待重发提示增加取消入口，用户可以放弃该重试提示而继续新一轮对话。
- 用户消息中的附件继续保留历史气泡，文件被清理后以不可用状态显示，不伪造仍可访问的预览。

## Kemo 网关接入

- Kemo Provider 支持 ModelCatalog 模型目录。只有配置已保存、协议为 `kemo` 且当前 API 密钥验证有效时，设置页才显示可选择模型气泡；其他协议和未验证状态继续使用传统输入框。
- 新增默认关闭的 `kemo_gateway_status` 全局拓展，使用独立状态 Token 获取网关版本、Provider 健康、调用统计和延迟等只读数据，并生成脱敏摘要、JSON 与图表。
- Chat/Kemo 兼容桥加固历史条目和工具调用 ID 的唯一性与对应关系，降低长历史续轮时的协议校验失败。
- 网关状态拓展不会随安装自动激活，也不会把管理密钥当作状态 Token；必须由用户明确授权并填写独立连接信息。

## 升级步骤

```bash
python update.py --module all
```

Linux 环境如没有 `python` 命令，可使用：

```bash
python3 update.py --module all
```

更新完成后完整重启 kemo-agent。Web 板块包含新的后端分层目录和前端资源，更新器会执行依赖安装与生产构建；如果构建失败，版本号不会被提交为 `0.7.0`。已启用的本地用户数据、消息平台模块和网关状态拓展凭据仍按更新器的保留规则处理。
