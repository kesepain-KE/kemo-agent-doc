# Kemo Gateway 0.7.3 更新说明

`0.7.3` 修正网关管理端调用日志小时选择器的着色口径：卡片颜色严格由实际终态结果贡献，取消或尚未终态的调用不会被误标为成功或失败。

## 着色口径修正

- 小时选择器始终显示该时间段的总调用次数；颜色不再由总调用量直接驱动。
- 成功次数独立贡献绿色渐变，失败次数独立贡献红色渐变，两者同时存在时按强度叠加，可直接看出该小时的吞吐量与失败压力。
- 取消或尚未终态的调用不计入任何颜色。
- 小时卡片提示扩展为「X 次调用，X 次成功，Y 次失败」。

## 展示细节

- CSS 变量由 `--hour-green` / `--hour-red` 改名为 `--hour-success` / `--hour-failure`，语义更准确。
- 图例文案改为「成功调用（648 次封顶）/ 失败调用（648 次封顶）」。

## 版本同步

- `version.json` 与前端 `package.json` 同步升至 `0.7.3`。
- 中英文 README 徽章更新为 `0.7.3`，并补充小时选择器着色口径说明。

## 升级建议

重新构建并部署网关前端即可生效，无需修改后端或 Provider 配置。
