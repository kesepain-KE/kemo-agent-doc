# kemo-agent-app 1.1.5 — 账号自动重连与输入法体验

1.1.5 解决了 App 长时间闲置、桥接服务重启后必须手动编辑账号并重新点击“连接并保存”的问题，同时收尾聊天输入法的交互细节。

## 本次更新

| 领域 | 变更 |
|------|------|
| 账号恢复 | App 启动或从后台回到前台时主动验证当前账号；桥接 Session 失效后使用 Keystore 中保存的设备 Token 与用户密码自动重新认证，不删除账号配置 |
| 会话同步 | 自动重连成功后恢复目标账号上一次的 App 活跃会话、聊天历史、上下文 Token 快照、运行状态、任务和拓展感知数据 |
| WebSocket | WebSocket 遇到 401/403 鉴权失败时触发账号恢复流程并重新建立设备连接，不再要求手动编辑账号 |
| 输入法 | 发送普通消息或运行中引导后自动清除焦点并隐藏输入法；点击聊天空白区域可以收起输入法，且不清空草稿 |
| 运行中提示 | 删除任务执行期间输入框上方的提示小字，保留实际发送、引导和暂停控件 |
| 后台保活 | 聊天流运行期间启动前台服务（dataSync）并显示低优先级「Kemo 正在回复」通知，切换到其他应用或熄屏后回复仍继续；流到终态自动停止 |
| 清除对话 | 清除对话现在会同步删除服务端会话并重置上下文，不再因下次状态请求重新恢复旧会话；删除/关闭会话透传 `client_id` |
| 版本合同 | `versionName=1.1.5`、`versionCode=7`、AGP 8.13.0 / Gradle 8.13、中英文资源、README、CI、发布合同和 `kemo-v1.1.5` 标签规则统一 |
