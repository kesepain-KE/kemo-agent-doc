# v0.9.0 更新说明

`v0.9.0` 将运行中引导从纯文本扩展为完整多模态输入。智能体正在执行当前轮次时，用户现在可以追加图片、音频、视频、普通文件，或只发送附件；媒体会在下一个 Provider/工具安全边界进入当前 Run。

## 运行中多模态引导

- 文本与附件使用同一个结构化引导信封，并通过 `guidance_id` 精确确认，重复文本和纯附件输入不会互相误匹配。
- Web 输入框在运行期间允许只发送附件，引导气泡会显示对应附件及排队、生效、完成或失败状态。
- 当前 Run 已关闭引导入口时，文本和全部附件作为一个整体转入下一轮；自动发送失败时仍保留附件，用户可以重试或取消。
- 已完成引导保存到所属轮次的 `guidance_details`，重新加载历史后仍可查看附件元数据；旧版纯文本 `guidance` 历史继续兼容。

## 媒体能力路由

- Kemo 协议根据网关返回的模型能力声明决定是否通过 Asset API 直传图片、音频、视频或普通文件。
- Chat 协议保持原有边界，只在模型明确支持图片时走视觉直传。
- 未被主模型直接接收的媒体仍登记为当前 Run 资产，可由 `multimodal` 或 `file` 工具按需处理，不会因为不是图片而丢失。
- API 边界与运行时都会验证附件所属用户、真实路径、内容签名、媒体类型、大小和校验和；Provider 不接收前端传入的任意路径、URL 或 Base64。

## 兼容性与验证

本次没有改变用户配置结构，也不需要迁移历史。纯文本引导 API、旧字符串邮箱和旧历史字段继续可用。

版本号同步为 `0.9.0`：根版本、core 和 web 为 `0.9.0`；agents 保持 `0.8.0`，plugins 保持 `0.8.1`。后端全量测试、前端全量测试和前端生产构建均已通过。

## 升级步骤

```bash
python update.py --module all
```

更新完成后完整重启 kemo-agent，使新的 Python 运行时和 Web 构建同时生效。
