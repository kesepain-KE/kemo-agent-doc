# kemo-agent-app 1.1.4 — 多账号与设备操作链路

1.1.3 解决了更新链路是否可信；1.1.4 回答的是两个更实际的问题——多账号切换后手机上的状态会不会串，以及智能体能不能安全地让手机做点什么。这一版完成了账号级状态隔离的收尾，并首次接入统一的设备操作协议。

## 本次更新

| 领域 | 变更 |
|------|------|
| 设备操作协议 | 全局 `kemo_app` 拓展通过统一 `device_action` 指令定向操作 App，首批安全接入系统闹钟、倒计时、日历日程和待办（`alarm.create` / `timer.start` / `calendar.event.create` / `todo.create`） |
| 安全边界 | 拒绝任意 Intent、组件名、URI、Shell 与远程代码；指令带 TTL 有效期、幂等命令 ID 与完整状态机；前台弹出确认框、后台经高优先级通知进入确认，最终由系统闹钟/日历界面承接，不静默写入系统数据 |
| 设备兼容 | OnePlus/ColorOS 日历 Intent 兼容；连接时上报设备型号、Android API 与每项动作的系统处理器可用性 |
| 账号隔离收尾 | 通知轮询游标与会话级临时凭据按账号隔离，切换账号互不串号；会话过期只清除对应账号并提示重新连接 |
| 思考档位 | Chat 协议固定五档、Kemo 按模型能力声明展示有序档位；配置页与聊天页均可切换，流式中禁用 |
| 上下文快照 | 聊天页顶部展示上下文 Token 占用与容量，长对话中可判断上下文余量 |
| 平板自适应 | 宽屏使用 NavigationRail 竖向导航、窄屏保持底部导航；移除竖屏锁定；连接/解锁页宽屏居中；PDF 预览增加渲染像素上限保护 |
| CI 与发布 | CI 新增 Release 构建；版本统一 1.1.4（versionCode 6），发布标签 `kemo-v1.1.4` |
