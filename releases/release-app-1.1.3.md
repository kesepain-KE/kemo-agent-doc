# kemo-agent-app 1.1.3 — App 内更新链路优化

1.1.2 解决了账号怎么安全搬走；1.1.3 回答的是另一个实际问题——当更新按钮按下去之后，链路是否可靠、下载是否可信。这一版集中优化了 App 内更新检查与下载的完整链路。

## 本次更新

| 领域 | 变更 |
|------|------|
| 版本标签修复 | `kemo-v1.1.3` 前缀不再被误判为预发布分隔符，更新提示恢复正常 |
| 检查缓存 | 检查结果缓存五分钟，反复进入关于页不再频繁请求 GitHub API |
| 限流降级 | GitHub API 失败（限流/404/网络）时自动降级抓取 GitHub 官方 Release 网页解析最新版；仍有缓存时兜底返回旧结果 |
| 多镜像下载 | 下载源支持 GitHub 官方优先 + 四个预装镜像（GHProxy.net / GH-Proxy Global / GH-Proxy.org / GH-Proxy IPv6）；「智能选择」官方优先、失败自动切换，也可手动指定单一源 |
| 安装前四重校验 | 下载文件必须通过 GitHub SHA-256 摘要比对、APK 包名匹配、版本号匹配与应用签名校验，任一失败明确提示，不会安装被篡改的 APK |
| 来源透明 | 关于页展示实际下载源、智能选择说明、安全提示、校验结果与最后失败的下载源 |
| 版本 | 构建配置、README 徽章、中英文版本资源、CI 与发布合同统一 1.1.3（versionCode 5） |
