# v1.2.8 更新说明（2026-09-13）

这是一次多用户 Web 工作区与运行可靠性更新。版本范围覆盖 v1.2.7 之后的全部提交，共 14 个提交、149 个文件。网页端补齐了运行中的可见性与可控性，后台收敛了历史生命周期、缓存与诊断，并把跨仓库的 Kemo 线路契约固定为可以离线复核的基准。

## 任务与子代理协作

- 前台任务计划在达到单轮工具上限后可以跨 Run 连续执行：续跑请求会带上计划 ID 与明确的执行约束，只执行尚未完成的步骤、遵守依赖关系、每步写回 `step_done` 或 `step_fail`，并且只在计划处于 running 时继续。completed、paused、failed、cancelled 或等待批准时停止，不创建或编辑新计划，也不自行批准、恢复或重置步骤。
- 新增 `subagent_progress` 运行事件：子代理在发起模型请求、执行工具和校验输出时上报阶段，调度队列同步回传运行状态且不重复发布排队态。网页把进度气泡挂在对应的 `subagent_dispatch` 工具卡片下方。
- 进度事件只携带阶段、代理名、任务 ID、工具名、轮次与计数，不转发子代理的提示词、推理、工具参数、结果、错误正文或任意 Provider 元数据。
- 消息跟进队列支持本轮引导的排序、取消与失败重试。

## 历史、记忆与持久化

- 定时任务产生的历史对话默认保留 7 天，可通过 `cron.history_retention_days` 调整，`0` 表示永久保留。清理只作用于已经结束的 `background:cron` 会话：候选先分页读取，再在会话锁与 SQLite 写租约内复核；运行中、记忆或摘要处理中、被其他进程占用的会话一律跳过。配置值非法时按失败关闭处理，不会删除数据。
- 网页工作区增加跨进程在线租约与启动巡检：离线但仍有数据的历史空间会被收束为已关闭并登记记忆，空对话在宽限期后清理。租约 90 秒自然过期，迟到的心跳不会重建已经清理的历史。
- 临时重要记忆的失效不再是布尔判断。热画像状态会在同一只读快照内核对来源计数与来源行，给出「未记录来源」「来源已删除或清理」「来源记忆已到期」「来源内容已更新」「来源已转为长期记忆」「来源记录异常」等原因；网页端编辑热画像后会返回重新计算的状态，编辑不会重建来源，也不会让已经失效的热画像重新生效。

## 缓存、诊断与运行日志

- 新增有界读缓存：带 TTL 与 LRU 上限、按来源配额、单飞加载与失效栅栏。每次读取前比对文件状态，缺失与读取失败不做负缓存，`.env` 始终绕过。配置、子代理清单、拓展与感知元数据的读取改走缓存入口。
- 系统状态新增独立分类日志视图：全部、后端、后端线程、终端与消息各自分页与计数，不再顺带触发完整运行状态聚合。线程快照只暴露编号、角色与存活状态，不返回线程名、栈或局部变量。
- 工具执行会记录后端与终端分类事件，只保存工具名、状态、耗时、错误类型与退出码，不复制参数、输出、提示词或异常正文。

## 网页端

- 文件空间支持按名称、最新日期和大小排序；临时记忆页面直接展示热画像的失效原因。
- 同一用户可以打开彼此独立的新标签页，用户卡片与侧边栏同步展示在线与生命周期状态。
- 修复暂停或停止请求与长任务续跑同时发生时的发送按钮状态竞态。

## 提示词与模块规范

- 新增全局知识专题《提示词职责、模块定义与编写规范》，统一人格、操作手册、知识索引、技能、插件、拓展与感知的职责边界、自动注入范围与按需读取规则。
- 技能与插件的发现摘要附带作用域与来源相对路径；拓展数据与感知出口标注数据来源、采集状态与最近更新时间，并明确它们是只读观测而不是执行指令。
- 全局人格补充指令与资料边界：来源分类不构成授权，验证范围服从用户约束，没有新证据时不重复同一失败调用。
- 拓展、感知、技能与用户人格模板同步补充适用范围、失败表达与来源说明。

## 协议与跨仓库契约

- Kemo 协议的版本校验收敛为单一实现：只接受 `MAJOR.MINOR` 形式，同一主版本内的前向兼容载荷继续可用，其他主版本直接拒绝。
- 资产内容的 `checksum_sha256` 增加 64 位十六进制校验并统一小写。
- 新增与 kemo-adapter-api 镜像的离线线协议基准，覆盖文本、动态推理档位、多轮工具结果、多模态、能力声明、模型目录、资产、Embedding、Rerank、终态响应、Usage 与 SSE 顺序去重。基准固定 SHA-256，可用 `--peer-root` 与对端逐字节核对，两个仓库各自使用本项目的生产协议模型执行。
- 仓库新增 `.gitattributes`，强制基准文件以 LF 检出，避免 Windows 默认换行转换让固定摘要失配。

## 修复

- 修复发布校验器用例在标签工作流中的环境泄漏：校验器会读取 `GITHUB_REF_TYPE` 与 `GITHUB_REF_NAME`，用例此前直接继承测试进程环境，标签触发时会拿当前发布标签与用例内示例版本比较并误报不一致。现在用例默认注入非标签上下文，并显式覆盖标签一致与不一致两条路径。

## 升级说明

- 从 1.2.7 升级无需迁移数据。`cron.history_retention_days` 为可选全局配置，缺失时按 7 天执行；设置为 `0` 可关闭定时任务历史清理。
- 定时任务历史清理与网页空对话清理都是破坏性动作，但只作用于已结束且不带活跃租约的会话；升级后首次启动网页会执行一次受限的对话空间巡检。
