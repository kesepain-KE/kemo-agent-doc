# 定时任务

定时任务让运行时在未来自动执行一次或周期性工作。任务保存在 `users/<user>/task_cron/`，由 RuntimeHost 中的 CronScheduler 扫描。

## 调度类型

| 类型 | 用途 |
|---|---|
| `once` | 在一个确定时间执行一次 |
| `daily` | 每天在指定时间执行 |
| `recurring` | 按固定间隔重复执行 |

自然语言创建或编辑任务时，系统先让 `time_plan` 子代理解析出自包含提示词和结构化时间参数，再交给 `task_time` 存储。这样可以避免主智能体直接猜测时间字段。

## 执行流程

调度器发现到期任务后，先原子领取任务，再调用主运行引擎执行提示词，最后保存结果和下一次运行时间。任务执行不经过 CLI。

默认轮询间隔为 30 秒。Provider 高负载时，普通用户任务可以推迟到后续扫描，任务仍保持到期状态，不会静默丢失。

::: warning 后台宿主
使用 `start_web.py --no-host` 时不会启动 RuntimeHost，Cron 和消息路由也不会被托管。需要后台任务时请正常启动 Web 服务。
:::
