# Web 界面使用

Web UI 是 React + TypeScript + Vite 构建的操作台，由 Python Web 服务提供 API。页面按真实工作过程组织，而不只是一个聊天框。

## 主要页面

| 路由 | 页面 | 主要用途 |
|---|---|---|
| `/chat` | 对话 | 流式对话、运行中追加引导、切换会话 |
| `/tasks` | 任务 | 管理任务计划与定时任务 |
| `/knowledge` | 知识 | 查看和维护分层知识 |
| `/memory` | 记忆 | 预览、纠正和删除记忆 |
| `/agents` | 子代理 | 查看当前用户可用子代理 |
| `/skills` | 技能 | 管理指令型技能 |
| `/sense` | 感知 | 查看、创建和刷新感知模块 |
| `/expand` | 拓展 | 查看与管理拓展模块 |
| `/files` | 文件 | 管理上传、下载和临时文件 |
| `/messages` | 消息 | 查看外部消息插件和日志 |
| `/status` | 状态 | 查看服务与并发状态 |
| `/runtime` | 运行时 | 查看子代理、消息和拓展库存 |
| `/profile` | 资料 | 头像、用户人格和全局人格 |
| `/settings` | 设置 | 查看脱敏后的运行配置 |

## 对话与运行中引导

聊天请求使用独立 `run_id`。运行中追加的引导进入专用队列，只会在 Provider 完成或工具调用结束后的安全边界注入，不会强行中断正在执行的网络请求或工具。

切换到其他页面不会切断正在进行的流式响应，返回对话页后会恢复当前运行现场。如果引导发送得太晚、工具循环已经结束，消息不会丢失，而会自动作为下一轮用户消息发送。用户消息按纯文本展示，不进行 Markdown 渲染。

长对话首次只加载最近 20 轮；向上滚动时再分页加载更早记录。右侧用户消息导航也只基于当前已加载内容，便于在长对话中快速定位自己之前发送的消息。

## 上传与粘贴

文件按钮和系统剪贴板都可以加入附件。在 Windows 复制截图、图片、压缩包或其他文件后，可以直接粘贴到输入框；附件可以不附带文字单独发送。单轮完成后，输入框上方的已上传提示会自动清除。

单个普通上传文件上限为 80 MB，同名文件会自动增加序号以避免覆盖。发送时前端只提交受控的上传引用，后端会验证文件仍位于当前用户的 `file_upload` 目录，再按 Provider 类型和多模态路由转换；图片数据不会作为 Base64 长期写入文本历史。

## 文件范围

Web 文件页只允许浏览、下载或删除 `file_upload`、`download` 和 `tmp` 中的普通文件；目录删除、路径穿越、符号链接、目录联接和隐藏缓存项会被拒绝。Windows 的 8.3 短路径与长路径别名会按文件系统身份识别，不会把同一个合法上传目录误判为越界。

::: tip 配置修改
Web 用户配置接口目前只提供脱敏只读镜像。Provider 等配置请通过用户配置文件或用户管理器修改。
:::
