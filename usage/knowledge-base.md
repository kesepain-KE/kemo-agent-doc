# 知识库

kemo-agent 提供用户、共享和全局三层知识库。知识以 Markdown 等本地资料为主，并通过各层索引参与检索。

## 三层优先级

1. `users/<user>/knowledge/`：当前用户私有，优先级最高。
2. `shared_knowledge/`：多个用户共享，可由 `knowledge.use_shared` 控制。
3. `global_knowledge/`：全局公共知识，可由 `knowledge.use_global` 控制。

新增知识默认写入用户层。只有在用户明确要求时，才应写到共享或全局层；私有信息不得进入共享层或全局层。

## 检索和注入

主提示词默认注入知识索引，不自动铺开所有正文。需要正文时再通过明确的检索机制读取，避免长期知识库直接耗尽上下文预算。

白名单和范围开关只控制主智能体。子代理的知识权限由各自 `agent-config.json` 独立决定。

## kemo-graph 替换

配置可按用户、共享、全局知识层分别启用图谱替换。某层启用后若图谱未连接，该层返回 `not_connected`，不会悄悄回退到原索引。

::: warning 数据边界
把资料写入共享或全局知识库前，请确认其中没有个人隐私、密钥或仅对单一用户授权的内容。
:::
