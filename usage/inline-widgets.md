# 正文内联组件

网页端的回复正文可以直接嵌入结构化组件。当一份对比、一组趋势或一段计算用图表达比用文字更清楚时，智能体会把它直接放在段落之间，而不是让你自己在脑中还原数据。

## 它是什么

组件是**正文的一部分**——不是工具调用，不是附件，也不是独立页面。它出现在哪里，取决于那一段话需要它在哪里：

- 一份成绩或方案对比，可能是一张对比卡片；
- 一组随时间变化的数据，可能是一条折线；
- 一段多步计算，可能是一张分步骤的计算卡。

每个组件都配有可读的文字说明。复制回复时，组件会还原成文字，而不是复制出一串原始数据。

## 有哪些组件

| 你想表达什么 | 会用到的组件 |
|---|---|
| 前后对比、方案比较、成绩变化 | 对比卡片 |
| 大小对比、趋势变化、组成占比 | 柱状图、折线图、饼图 |
| 一屏摘要、进度与容量 | 指标网格、进度列表 |
| 步骤、时间线、状态演进 | 时间线 |
| 属性、参数、结果详情 | 键值表 |
| 提示、结论、警告 | 提示卡 |
| 列表 | 有序 / 无序列表 |
| 计算步骤与结果 | 计算卡 |
| 结构化数据 | 数据表格，支持筛选、排序与分页 |
| 折叠的说明或推导 | 折叠面板、标签页、手风琴 |
| 变更前后对照 | 差异对照 |
| 标签、版本、状态摘要 | 徽章组 |
| 多系列、散点、热力、仪表 | 系列图、散点图、热力图、仪表盘 |
| 议程与看板 | 日历、看板（只读） |
| 图片 | 单图、图集、轮播 |
| 收集少量信息 | 表单 |

除这些之外，任何其他名称的组件也会以通用卡片的形式展示，不会直接报错。

## 可以点击的地方

部分组件带有交互，但都只做三件事，而且**只在你亲自点击之后才发生**：

- 把一段文字**填入输入框**；
- **发送**一条消息；
- **复制**一段文字。

例如"建议追问"会把问题填进输入框等你确认。回复正在生成时，点击"发送"不会并发开启第二次运行，而是把文字放进输入框等待你处理。

## 它不会做的事

- **不执行代码。** 组件里的内容一律当文本显示，不会运行脚本、事件处理器或样式。
- **不自动动作。** 不会自动发送、自动批准，也不会直接调用工具或接口。
- **不抓取外网。** 图片只引用站内已有的文件。
- **不改变状态。** 只影响当前页面的显示，不改动任务、文件或记忆。

## 显示不完整时

如果某个组件没有生成完整，页面会显示一句占位说明，而不是把半截数据暴露出来，正文其余部分照常阅读。

复制回复时，组件会被替换成对应的文字说明。
