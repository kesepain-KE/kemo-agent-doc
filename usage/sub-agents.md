# 子代理

子代理是为特定职责配置的独立执行单元。它们拥有自己的提示词、模型档位、工具和知识权限，不自动继承主会话全部内容。

## 内置子代理

| 名称 | 职责 |
|---|---|
| `context_manage` | 上下文摘要与工具/思考压缩 |
| `self_improve` | 记忆提取与整理 |
| `memory_temporary_important` | 临时重要记忆维护 |
| `task_plan` | 计划生成与编辑 |
| `time_plan` | 自然语言时间解析 |
| `history_summary` | 已关闭会话的标题与摘要 |

## 发现与授权

运行时每次扫描 `agents/` 和 `users/<user>/agents/`，新增或调整用户子代理后通常无需重启。用户子代理不能覆盖内置名称。

`agent-config.json` 是强制授权边界：只有白名单里的插件和技能、明确允许的知识层才能进入子代理。`subagent_dispatch` 不会再下发给子代理，避免递归调度链。

## 多轮工具循环

子代理可以在同一次任务中连续执行多轮“模型 → 工具 → 模型”。Provider 返回的 reasoning ID 只保证在单次响应内唯一，因此运行时把响应加入下一轮请求前会生成本地唯一 ID；reasoning 正文、摘要与 Provider 状态保持不变，工具调用和工具结果仍通过原 `call_id` 配对。这一处理对 Kemo 与兼容 Chat Provider 使用同一套子代理运行边界。

## 运行期限与状态

子代理整体期限来自 `agent_runtime.default_timeout`，默认 600 秒，与子代理内部每一次工具调用的超时相互独立。同步调度会按子代理期限等待，不会在普通工具默认的 240 秒到达时提前截断。

期限到达后，运行时会请求协作式取消并等待短暂清理：

- `timed_out`：执行线程已经退出。
- `timed_out_running`：已请求取消，但线程没有在清理窗口内退出，需要查看运行日志。

后者不代表线程已被强制终止。Python 线程不会被不安全地杀死，自定义执行器和插件必须主动响应取消信号。

::: warning 自定义执行器
`executor.py` 会被 kemo-agent 进程直接导入执行，不提供代码沙箱。只安装或编写你完全信任的本地代码。
:::
