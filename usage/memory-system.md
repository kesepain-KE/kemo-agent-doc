# 潮汐记忆系统

潮汐记忆不把全部聊天永久堆积为记忆，而是让内容在使用中获得权重，并按七天、一个月、半年、永久四档流动。

## 四档生命周期

| 档位 | 有效期 | 晋级阈值 | 下一档 |
|---|---:|---:|---|
| `seven_days` | 7 天 | 3 | `one_month` |
| `one_month` | 30 天 | 10 | `half_year` |
| `half_year` | 180 天 | 60 | `permanent` |
| `permanent` | 永久 | — | — |

到期时，达到阈值的内容进入下一档并从 0 重新累计；未达阈值的内容会删除，而不是降级保留。

## 权重怎样增加

记忆被实际注入并参与一次成功任务、被正文修改或被自我改进流程命中时可以加权。这些行为共享每日锁：同一记忆在同一自然日合计最多 `+1`。仅搜索命中、失败或取消都不加权。

## 存储和控制

临时三层由 Markdown 正文和同目录 `data.json` 元数据组成；永久层只保存 Markdown。用户可以查看、纠正或删除记忆。

::: danger 敏感信息
API Key、Token、密码、Cookie 和私钥不得写入长期记忆。运行时也会进行模式过滤，但不要依赖过滤器替代正确操作。
:::

临时重要记忆是由专门子代理维护的近期热画像。它引用已有临时记忆碎片形成可重建视图，不改变源碎片的权重、到期或晋级规则；被热画像引用的碎片不会在普通临时记忆段重复注入。热画像文件不得删除、清空或写入空内容。

自动提取会把连续的待处理轮次组成批次，一次模型分析可产生多条候选，再统一匹配永久记忆、合并重复内容并批量落盘。相同批次带有稳定操作标识，失败重试不会重复创建或重复加权。
