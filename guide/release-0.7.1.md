# v0.7.1 更新说明

`v0.7.1` 是长对话右侧用户消息导航的修复版本。它把原来的固定 20 项角度列表改为 10 项动态滚轮，同时补齐更早历史分页与导航窗口之间缺失的衔接。此次更新不修改历史存储格式、Provider 协议或后端分页 API。

## 10 项动态导航窗口

- 右侧最多显示 10 个用户消息刻度和 10 张轮次预览卡片，减少长列表在单屏中的拥挤感。
- 这 10 项会围绕当前视口或当前悬停轮次移动，不再永久固定为已加载历史中的最后 10 项。
- 用户滚动聊天正文、使用滚轮或方向键切换轮次时，导航窗口会同步前后移动。
- 点击轮次卡片仍会把聊天正文平滑定位到对应用户消息。

## 修复更早轮次无法进入导航

旧实现虽然能从后端成功加载上一页历史，却始终对全部标记执行固定的末尾截取。结果是更早消息已经出现在聊天正文中，但右侧滚轮永远只显示最新一组轮次。

现在到达当前最早已加载轮次时，可以继续请求上一页；加载完成后，导航会移动到刚出现的上一轮。聊天正文顶部的“加载更早对话”、右侧导航顶部入口和滚轮边界共用同一分页逻辑，并继续保留加载前的正文滚动位置。

## 180°中心滚轮

- 悬停最上方、中间或最下方任意刻度时，对应轮次都会旋转到 180°正左侧中心位并突出显示。
- 更早轮次重新分布在 90°—180°区间，更新轮次重新分布在 180°—270°区间，时间顺序保持不变。
- 当前项不再停留在它原先的固定角度，整个卡片组会像滚轮一样围绕当前项重新排布。

## 升级步骤

```bash
python update.py --module all
```

Linux 环境如没有 `python` 命令，可使用：

```bash
python3 update.py --module all
```

更新完成后重启 kemo-agent。此次主要变更位于 Web 前端，更新器会重新安装前端依赖并执行生产构建；构建失败时不会提交新版本号。
