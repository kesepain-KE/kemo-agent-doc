# kemo-agent-app：Kemo 生态的移动客户端

> 当前版本：1.0 — 首个正式版本，覆盖连接与两级认证、流式对话、任务计划与定时任务、文件管理、拓展感知开关、运行状态、智能体配置、安全解锁与桌面小组件。

[kemo-agent-app](https://github.com/kesepain-KE/kemo-agent-app) 是 Kemo 生态中面向 Android 的独立项目，也是 kemo-agent 的官方移动客户端。

它不替代 kemo-agent 的网页端或命令行；它处理的是另一类问题：当智能体已经部署在服务器上持续工作时，如何让用户出门在外也能随时与它对话、查看任务、管理文件、调整配置。

## 它在生态中的位置

```text
手机上的用户
  ↓
kemo-agent-app
  → 连接桥接服务，完成设备 Token 与账号两级认证
  ↓  Kemo 协议
kemo-adapter-api（桥接服务）
  → 转发请求并鉴权，安全获取模型列表
  ↓
kemo-agent
  → 对话、记忆、任务、文件、拓展与感知运行时
```

三个项目各司其职：

- **kemo-agent-app** 是移动端入口，负责把 kemo-agent 的能力带到 Android 设备上；
- **kemo-agent** 是 Agent Runtime，负责对话、计划、工具、记忆和编排；
- **kemo-adapter-api** 是模型网关，负责桥接与两级认证，并把 Kemo 请求路由到已授权的模型 Provider。

可以把它们理解为：

> kemo-agent-app 负责随身携带；kemo-agent 负责持续工作；kemo-adapter-api 负责安全连接。

## kemo-agent-app 解决什么问题

网页端能完成所有管理工作，但它要求一台能打开浏览器的设备。kemo-agent-app 把 Kemo 生态的日常高频能力收敛到手机里：

- 想继续一段对话，而不是等到回到电脑前；
- 想看一眼任务计划的进展，批准或暂停某个步骤；
- 想确认服务是否在线、运行指标是否正常；
- 想上传一份文件、下载智能体生成的结果；
- 想调整模型、Provider 或白名单配置；
- 想在不信任的环境里快速安全地打开应用。

这些场景不需要完整工作台，只需要一个随时在身边的入口。

## 主要能力

### 连接与两级认证

连接页配置桥接服务地址，并完成两级认证：设备 Token 与用户账号密码。

- 凭证支持记住，使用 Android Keystore 加密保存，最长保留 7 天；
- 支持多个账号并存，在「我的」页随时切换；
- 可选设置 App 密码，作为打开应用时的第一道防线。

### 助手对话

聊天页围绕真实对话组织：

- 流式输出，逐字呈现智能体回复；
- Markdown 渲染，代码块、列表与引用清晰可读；
- 展示思考过程与工具调用（参数、结果、成功或失败）；
- 显示 Token 消耗、缓存命中与响应耗时；
- 历史会话支持保存、切换、删除，以及一键清除、手动压缩上下文；
- 支持添加附件，把文件交给智能体处理。

### 任务计划与定时任务

任务页同时承载任务计划与定时任务：

- 任务计划按状态筛选（待批准、运行中、已完成、失败），展示步骤进度；
- 批准、暂停、恢复、中止，随时掌握节奏；
- 定时任务可以查看与编辑，调度参数一目了然；
- 桌面小组件展示待批准数量与最新任务，点击直达任务页；
- `kemo://task` 深链可从任意入口直接打开任务界面。

### 文件工作区

文件页把上传文件与智能体生成文件分开管理：

- 浏览服务器工作区目录，进入任意层级；
- 上传本地文件，下载或删除远程文件；
- 常见格式直接在 App 内预览；无法解析的文件提示下载后交由系统应用打开；
- 下载位置可自定义，也可恢复系统默认目录。

### 拓展与感知

拓展感知页列出当前可用的拓展与感知模块：

- 查看模块名称、层级与启用状态；
- 直接打开或关闭模块（写入白名单），调整注入策略；
- 查看感知来源与注入数据，了解智能体正在「看到」什么。

### 运行状态

状态页显示 Kemo 服务在线状态与最新运行快照：

```text
版本 · 上游连接 · 运行健康 · 会话 · 消息队列 · 缓存 · 上下文 · 拥塞 · 模型服务 · 运行指标
```

### 智能体配置

配置页与网页版当前用户配置保持一致：

```text
模型与 Provider（Base URL · API Key · 思考强度 · 流式输出 · 多模态输入）
子智能体模型（default · cheap · reasoning）
多模态模型（图片 · 语音 · 视频）
知识范围 · 共享技能/拓展/感知/插件白名单
拓展与感知注入策略 · 任务计划自动接受
```

模型列表由桥接服务使用已保存的 Kemo 凭证安全获取，不在手机端保存服务商密钥。

### 安全与隐私

- 连接凭证使用 Android Keystore 加密保存；
- 支持生物识别 / 设备凭据解锁，也可设置 App 密码；
- 后台 5 分钟自动锁定，验证身份后才能修改安全设置；
- 敏感操作由服务端鉴权，App 只扮演受信任的入口。

## 如何连接 kemo-agent

1. 部署并运行 kemo-agent 与 kemo-adapter-api 网关，配置账号与设备 Token；
2. 安装并打开 kemo-agent-app；
3. 在连接页填写桥接服务地址（模拟器访问宿主机默认 `http://10.0.2.2:8742`）、设备 Token、用户名与用户密码；
4. 连接成功后即可开始对话与管理任务。

## 获取与构建

环境要求：Android Studio（最新稳定版）、JDK 17、Android SDK 36。

```bash
git clone https://github.com/kesepain-KE/kemo-agent-app.git
cd kemo-agent-app
./gradlew assembleDebug
```

构建产物位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```
