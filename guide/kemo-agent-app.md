# kemo-agent-app：Kemo 生态的移动客户端

> 当前版本：1.1.2 — 账号可导出为密码加密的 `.kemoaccount` 文件并在设备间导入迁移（PBKDF2-HMAC-SHA256 + AES-256-GCM，凭据重新经 Keystore 保存）；1.1.1 带来保存账号直入、本地重命名、背景即时刷新与空集合修复；1.1.0 在 1.0 首个正式版本之上带来聊天数学公式渲染与媒体卡片、运行中引导、停止生成与重新回复、聊天通知轮询、图片/视频背景主题、卡片详情弹层、可搜索模型选择器、音频/视频/PDF 预览，以及 App 内更新检查与关于页。

[kemo-agent-app](https://github.com/kesepain-KE/kemo-agent-app) 是 Kemo 生态中面向 Android 的独立项目，也是 kemo-agent 的官方移动客户端。

它不替代 kemo-agent 的网页端或命令行；它处理的是另一类问题：当智能体已经部署在服务器上持续工作时，如何让用户出门在外也能随时与它对话、查看任务、管理文件、调整配置。

## 它在生态中的位置

```text
手机上的用户
  ↓
kemo-agent-app
  → 连接 kemo_app 桥接服务，完成设备 Token 与账号两级认证
  ↓  HTTP / SSE / WebSocket
kemo-agent
  ├─ kemo_app 桥接服务（全局拓展，独立端口）
  │    → 对话、引导、取消、历史、任务、文件、状态、事件推送
  │    → 转发受权操作到框架 Web API
  └─ 对话、记忆、任务、文件、拓展与感知运行时
  ↓  Kemo 协议
kemo-adapter-api（模型网关）
  → 转发请求并鉴权，路由到已授权的模型 Provider
```

三个项目各司其职：

- **kemo-agent-app** 是移动端入口，负责把 kemo-agent 的能力带到 Android 设备上；
- **kemo-agent** 是 Agent Runtime，负责对话、计划、工具、记忆和编排，并通过内置的 `kemo_app` 全局拓展为 App 提供独立的桥接接口；
- **kemo-adapter-api** 是模型网关，负责把 Kemo 请求路由到已授权的模型 Provider。

可以把它们理解为：

> kemo-agent-app 负责随身携带；kemo-agent 负责持续工作与桥接；kemo-adapter-api 负责安全连接。

## kemo-agent-app 解决什么问题

网页端能完成所有管理工作，但它要求一台能打开浏览器的设备。kemo-agent-app 把 Kemo 生态的日常高频能力收敛到手机里：

- 想继续一段对话，而不是等到回到电脑前；
- 想看一眼任务计划的进展，批准或暂停某个步骤；
- 想确认服务是否在线、运行指标是否正常；
- 想上传一份文件、下载智能体生成的结果；
- 想调整模型、Provider 或白名单配置；
- 想在不信任的环境里快速安全地打开应用。

这些场景不需要完整工作台，只需要一个随时在身边的入口。

## 主要能力

### 连接与两级认证

连接页配置桥接服务地址，并完成两级认证：设备 Token 与用户账号密码。

- 凭证支持记住，使用 Android Keystore 加密保存，最长保留 7 天；
- 支持多个账号并存，在「我的」页随时切换；
- 可选设置 App 密码，作为打开应用时的第一道防线。

### 助手对话

聊天页围绕真实对话组织：

- 流式输出，逐字呈现智能体回复，支持数学公式渲染；
- Markdown 渲染，代码块、列表与引用清晰可读；
- 展示思考过程与工具调用（参数、结果、成功或失败），并显示工具耗时；
- 展示智能体生成的媒体卡片（图片、视频、音频），点击即可预览与缓存下载；
- 回复期间可以继续发送引导，智能体将在安全边界接收；
- 可以随时停止生成，或重新回复上一轮；
- 显示 Token 消耗、缓存命中与响应耗时，以及上下文用量进度；
- 历史会话支持保存、切换、删除，以及一键清除、手动压缩上下文；
- 支持添加附件，把文件交给智能体处理。

### 聊天通知

App 在后台通过轮询检查会话状态，回复完成时推送通知，任务与定时事件通知也统一到通知渠道管理。

### 任务计划与定时任务

任务页同时承载任务计划与定时任务：

- 任务计划按状态筛选（待批准、运行中、已完成、失败），展示步骤进度；
- 点击计划或定时任务卡片即可在底部弹层查看完整详情（状态、调度参数、描述、引用）；
- 批准、暂停、恢复、中止，随时掌握节奏；
- 定时任务可以查看与编辑，调度参数一目了然；
- 桌面小组件展示待批准数量与最新任务，点击直达任务页；
- `kemo://task` 深链可从任意入口直接打开任务界面。

### 文件工作区

文件页把上传文件与智能体生成文件分开管理：

- 浏览服务器工作区目录，进入任意层级；
- 上传本地文件，下载或删除远程文件；
- 常见格式直接在 App 内预览，音频、视频与 PDF 也支持；无法解析的文件提示下载后交由系统应用打开；
- 上传限制提升至 80 MB；
- 下载位置可自定义，也可恢复系统默认目录。

### 拓展与感知

拓展感知页列出当前可用的拓展与感知模块：

- 查看模块名称、层级与启用状态；
- 直接打开或关闭模块（写入白名单），调整注入策略；
- 查看感知来源与注入数据，了解智能体正在「看到」什么。

### 智能体配置

配置页与网页版当前用户配置保持一致：

```text
模型与 Provider（Base URL · API Key · 思考强度 · 流式输出 · 多模态输入）
子智能体模型（default · cheap · reasoning）
多模态模型（图片 · 语音 · 视频）
知识范围 · 共享技能/拓展/感知/插件白名单
拓展与感知注入策略 · 任务计划自动接受
```

模型列表由桥接服务使用已保存的 Kemo 凭证安全获取，不在手机端保存服务商密钥；配置页通过可搜索的模型选择器挑选模型，也支持直接输入模型名。

### 运行状态

状态页以结构化面板展示 Kemo 服务运行快照：

```text
服务连接状态 · 上下文用量与轮次进度 · 协议与当前模型 · Token 统计（总/发送/接收/缓存）· 当前用户 · 知识库文档数
```

### 背景主题

设置页可以选择一张图片或一段视频作为全局背景，启用后应用切换为半透明色板并让系统栏透明，聊天页抽屉全屏沉浸；也可以一键恢复默认主题。

### 更新检查与关于页

「我的」页的 App 版本入口进入关于页，展示项目信息、开源许可与维护者信息，并支持从 GitHub Releases 检查新版本、下载 APK 并安装。

### 账号管理

- 长按账号卡片可编辑账号或删除账号；
- 删除账号会同时清除该账号在本机保存的加密凭证。

### 安全与隐私

- 连接凭证使用 Android Keystore 加密保存；
- 支持生物识别 / 设备凭据解锁，也可设置 App 密码；
- 后台 5 分钟自动锁定，验证身份后才能修改安全设置；
- 敏感操作由服务端鉴权，App 只扮演受信任的入口。

## 如何连接 kemo-agent

1. 在 kemo-agent 上启用 `kemo_app` 全局拓展（Android App 桥接服务，独立端口运行，提供 HTTP/SSE/WebSocket 接口），并配置设备 Token 与 App 账号；
2. 安装并打开 kemo-agent-app；
3. 在连接页填写桥接服务地址（模拟器访问宿主机默认 `http://10.0.2.2:8742`）、设备 Token、用户名与用户密码，完成两级认证；
4. 连接成功后即可开始对话与管理任务；回复完成后 App 会在后台收到通知，生成的图片、音视频与文件可直接预览。

## 获取与构建

环境要求：Android Studio（最新稳定版）、JDK 17、Android SDK 36。

```bash
git clone https://github.com/kesepain-KE/kemo-agent-app.git
cd kemo-agent-app
./gradlew assembleDebug
```

构建产物位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```
